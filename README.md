# Taste of Africa 🌍🍲

A responsive website celebrating the diversity, flavours, and culinary traditions of African cuisine.

## About the Project

Taste of Africa is a web development project designed to introduce visitors to African food and culinary culture. It allows users to explore traditional dishes, discover regional cuisines, follow recipes, and learn about the cultural significance of food across Africa.

The project focuses on creating an engaging and accessible experience using HTML, CSS, and JavaScript.

## Features

### 🏠 Homepage
- Introduction to African cuisine.
- Featured African dishes.
- Links to culinary regions.
- Food trends and cultural highlights.
- Embedded introductory video.

### 🍽️ Recipes
- Dedicated pages for traditional African dishes.
- Ingredient lists and cooking instructions.
- Expandable recipe instructions.
- Embedded cooking tutorials.
- Ingredient quantity scaling.
- Save favourite recipes using browser local storage.

### 🌍 Culinary Regions
Explore the food cultures of three African regions:

- **East Africa:** Traditional dishes, ingredients, and cooking practices.
- **West Africa:** Regional staples, flavours, and culinary traditions.
- **North Africa:** Traditional ingredients, dishes, and cooking techniques.

Each regional page includes cultural information, example dishes, and an embedded video.

### 🌓 Theme Switching
- Toggle between light and dark mode.
- Theme preference is saved using browser local storage.

### 📩 Contact Form
- Name and email fields.
- Country input with datalist suggestions.
- Optional favourite African dish field.
- Message textarea.
- Form validation and dynamic confirmation feedback.

### 📱 Responsive Design
- Designed for desktop, tablet, and mobile screens.
- Responsive navigation and content layouts.
- Adaptable video and map embeds.

## Getting Started

You can run this project locally without installing additional dependencies.

1. Clone the repository:

```bash
git clone https://github.com/tkongolo24/taste_of_africa_website_project.git
```

2. Navigate into the project directory:

```bash
cd taste_of_africa_website_project
```

3. Open the project folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Interactive Functionality

The website uses JavaScript to provide:

- Recipe filtering by region.
- Favourite recipe management with local storage.
- Ingredient quantity scaling.
- Persistent light and dark theme preferences.
- Contact form validation.
- Dynamic form confirmation messages.
